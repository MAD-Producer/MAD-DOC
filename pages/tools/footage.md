# 素材与工程管理

::: tip 要点
- “免费下载”“无水印”“网上找的”都不等于获得了许可。素材的来源和许可要随手记下来。
- 导入失败时，先用 MediaInfo 看清是**容器**、**编码**还是**位深／帧率**的问题，再决定拆封装、转码还是生成代理。
- 只是容器不支持就拆封装（不损画质）；编码太难解就转成中间格式；电脑带不动就用代理。
- 原始素材放进只读文件夹，用固定的目录结构和版本号管理工程。
- 编码原理和导出设置见[视频基础与编码](/tools/encoding)。
:::

## 素材可以从哪里来

| 来源 | 适用内容 | 要记下什么 |
| --- | --- | --- |
| 自购实体介质 | 动画、电影、音乐、游戏特典 | 版本、地区、盘号、提取日期；能否绕过技术保护按当地法律判断 |
| 正版数字购买／下载 | 官方提供下载文件的内容 | 商店、订单或许可证、格式、使用范围 |
| 版权方素材包 | PV、预告、媒体包、比赛指定素材 | 发布方、原页面、使用条款、日期 |
| 开放许可平台 | 图片、字体、音效、音乐、视频 | 具体许可版本、作者、署名要求、下载日期 |
| 公共领域 | 保护期已过或明确放弃权利的素材 | 判断依据和所在法域 |
| 作者授权 | 插画、摄影、动画、音乐、工程 | 授权人、范围、平台、期限、能否修改和再分发 |
| 自制素材 | 绘画、实拍、三维、录音 | 参与者，以及用到的模型、字体、贴图 |

本站不收录盗版片源站、破解工具或规避平台版权识别的方法。

## MKV、HEVC、10-bit 为什么经常导入失败

先分清三件事：

- **容器**：MP4、MKV、MOV，是装着多条轨道的“盒子”；
- **编码**：H.264、H.265／HEVC、AV1、ProRes、DNxHR，决定视频怎么压缩；
- **像素与色彩**：8-bit／10-bit、4:2:0／4:2:2、HDR／SDR，决定画面怎么表示。

软件说“不支持 .mkv”，多半是容器问题；说 HEVC 有问题，可能是系统缺解码器、位深太高、硬件不支持或是可变帧率。用 MediaInfo 或 `ffprobe` 看清实际信息再动手。**改扩展名不会改变容器或编码。**

## 拆封装、转码、代理怎么选

| 做法 | 什么时候用 | 画质 | 工具 |
| --- | --- | --- | --- |
| 拆封装（remux） | 只是容器不被剪辑软件支持 | 无损失 | MKVToolNix、FFmpeg |
| 转码（transcode） | 编码太难解，剪辑卡顿或无法导入 | 转成中间编码几乎无损，但文件很大；再转成有损格式会有代际损失 | FFmpeg、HandBrake |
| 代理（proxy） | 电脑带不动原素材 | 只用于剪辑，导出时自动换回原文件 | 剪辑软件自带 |

## 帧率

动画素材可能混有 23.976、24、25、29.97、30 和可变帧率。动手前先确定：

1. 时间线用什么帧率；
2. 素材是真实高帧率，还是重复帧、隔行或可变帧率；
3. 变速用帧混合、光流还是逐帧重建；
4. 长时间线里音画会不会慢慢不同步。

补帧不是万能的画质增强。遮挡、快速运动、闪光、粒子和切镜处容易出现拉伸、重影和“果冻”，要逐个镜头检查，不适合的镜头保留原帧率。

## 色彩与画面

- 有限范围／全范围解释错误，会让黑色发灰或死黑、高光溢出；
- HDR 素材放进 SDR 时间线，需要正确的色彩管理和映射；
- 锐化救不回低码率压缩已经丢掉的细节；
- 去字幕、去台标会破坏原画，不能说成“无损”；
- 统一调色前先想清楚镜头的作用，别把昼夜和回忆的层次全部抹平。

## 推荐目录结构

```text
project-name/
├─ 00_admin/          # 简介、授权、来源清单、版本记录
├─ 01_audio/          # 音乐、对白、音效
├─ 02_footage/        # 原始素材，只读
├─ 03_proxy/          # 可重建的代理
├─ 04_graphics/       # 图片、字体说明、矢量、贴图
├─ 05_project/        # 剪辑、合成、三维工程
├─ 06_renders/        # 中间渲染和缓存
├─ 07_exports/        # 母版、发布版、封面、字幕
└─ 99_archive/        # 清单、校验值、最终归档
```

文件名写清内容、镜头或集数、版本号和日期。用 `v03` 这样的版本号，不要用“最终版2_真的最终”。

## 素材清单模板

| 字段 | 示例 |
| --- | --- |
| `asset_id` | anime-a_ep03_001 |
| 名称 | 作品 A 第 3 集 |
| 来源 | 版权方／商店／作者 |
| 来源地址 | 原页面或订单记录 |
| 取得日期 | YYYY-MM-DD |
| 许可／用途 | 个人练习、比赛指定、CC BY 4.0 等 |
| 容器／编码 | MKV / HEVC Main10 |
| 帧率 | 23.976 CFR |
| 分辨率 | 1920×1080 |
| 音轨／字幕 | 日语 FLAC、中文字幕 ASS |
| 校验值 | SHA-256 |
| 备注 | HDR、需代理、不可再分发 |
