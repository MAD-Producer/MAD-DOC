# 素材、编码与工程管理

::: tip 本页边界
这里只说明合法来源、封装与编码知识、工程管理和归档方法。不会列出盗版动画下载站、破解工具或绕过平台版权识别的方法。
:::

## 素材来源

| 来源 | 适用内容 | 入库时必须记录 |
| --- | --- | --- |
| 自购实体介质 | 动画、电影、音乐、游戏附赠内容 | 版本、地区、盘号、提取日期；是否允许绕过技术保护需按所在地法律判断 |
| 正版数字购买／下载 | 官方提供可下载文件的内容 | 商店、订单或许可证、下载格式、使用范围 |
| 版权方素材包 | PV、预告、媒体包、比赛指定素材 | 发布主体、原页面、使用条款、发布日期 |
| 开放许可平台 | 图片、字体、音效、音乐、视频 | 具体许可版本、作者、署名要求、下载日期 |
| 公共领域 | 权利期限届满或明确投入公共领域的素材 | 法域、判断依据、原始档案 |
| 作者授权 | 插画、摄影、动画、音乐、工程文件 | 授权人、范围、平台、期限、可否修改和再分发 |
| 自制素材 | 绘画、实拍、三维、录音 | 参与者、模型／字体／贴图等第三方依赖 |

“免费可下载”“无水印”“网上找的”都不是许可。

## 为什么 MKV、HEVC、10-bit 经常导入失败

三个概念要分开：

- **容器**：MP4、MKV、MOV，像装着多条轨道的盒子；
- **编码**：H.264、H.265／HEVC、AV1、ProRes、DNxHR，决定视频如何压缩；
- **像素与色彩**：8-bit／10-bit、4:2:0／4:2:2、HDR／SDR，决定表示方式。

软件显示“.mkv 不支持”，可能是容器不受支持；显示 HEVC 问题，可能是系统解码器、位深、硬件支持或可变帧率问题。先用 MediaInfo 或 `ffprobe` 查看，而不是反复改扩展名。

## 拆封装、转码和代理

### 拆封装（remux）

只把音视频轨道从一个容器换到另一个容器，不重新压缩。速度快、无画质损失，但不能解决宿主不支持该编码的问题。MKVToolNix 和 FFmpeg 都能处理。

### 转码（transcode）

重新解码并编码。可以把高压缩交付格式转换为更适合剪辑的中间编码，但会占用更多空间；如果再次使用有损编码，也会产生代际损失。

### 代理（proxy）

为剪辑生成低分辨率、易解码的临时副本，最终输出时自动连接原文件。代理不会提高原始画质，重点是提高交互流畅度。

## 帧率处理

动画素材可能混合 23.976、24、25、29.97、30 或可变帧率。处理前应确定：

1. 时间线目标帧率；
2. 素材是真实高帧率、重复帧、隔行还是可变帧率；
3. 变速是否需要帧混合、光流或逐帧重构；
4. 音频同步是否在长时间线中漂移。

补帧不是“画质增强”的通用按钮。遮挡、快速运动、闪光、粒子和镜头切换都可能产生拉伸、重影和“果冻”伪影。应逐镜检查，必要时分离前后景、改用混帧或保留原帧率。

## 色彩与画面一致性

- 不要混淆有限范围／全范围，错误解释会造成灰黑或过曝；
- HDR 素材进入 SDR 时间线需要正确的色彩管理与映射；
- 不要用极重锐化掩盖低码率压缩；
- 去字幕、台标或烧录文字通常会破坏原画，不应伪装成“无损”；
- 统一颜色之前先判断镜头的叙事功能，避免把昼夜和回忆层次全部抹平。

## 推荐目录结构

```text
project-name/
├─ 00_admin/          # 简介、授权、来源清单、版本记录
├─ 01_audio/          # 音乐、对白、音效
├─ 02_footage/        # 原始素材，只读
├─ 03_proxy/          # 可重建的代理
├─ 04_graphics/       # 图片、字体说明、矢量、贴图
├─ 05_project/        # 剪辑、合成、三维工程
├─ 06_renders/        # 中间渲染和缓存
├─ 07_exports/        # 母版、发布版、封面、字幕
└─ 99_archive/        # 清单、校验值、最终归档
```

文件名至少包含：内容、镜头或集数、版本、日期。不要依赖“最终版2真的最终版”。

## 素材清单模板

| 字段 | 示例 |
| --- | --- |
| `asset_id` | anime-a_ep03_001 |
| 名称 | 作品 A 第 3 集 |
| 来源主体 | 版权方／商店／作者 |
| 来源地址 | 原页面或订单记录 |
| 取得日期 | YYYY-MM-DD |
| 许可／用途 | 个人练习、比赛指定、CC BY 4.0 等 |
| 容器／编码 | MKV / HEVC Main10 |
| 帧率 | 23.976 CFR |
| 分辨率 | 1920×1080 |
| 音轨／字幕 | 日语 FLAC、中文字幕 ASS |
| 校验值 | SHA-256 |
| 备注 | HDR、需代理、不可再分发 |
