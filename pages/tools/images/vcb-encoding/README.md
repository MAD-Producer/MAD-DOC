# VCB-Studio encoding guide images

This directory contains local copies of images used by the VCB-Studio public
guides and reproduced in `pages/tools/encoding.md`.

- Source: https://github.com/vcb-s/guides
- Published guide: https://guides.vcb-s.com/
- License: CC BY-SA 4.0
- License text: https://creativecommons.org/licenses/by-sa/4.0/
- Source revision: `1c11b4c8f03f9e968ad1b32b757c6d5b4d3e0cd0`

The files were renamed for stable, descriptive local URLs. Their image content
was not modified. Attribution and the originating guide chapter are provided in
the page captions.
