# 研究方法与问卷

现有 MAD·AMV 历史资料的最大问题不是“完全没有文章”，而是样本不透明、回忆与事实混写、原始链接失效。下面是一套可公开复用的采集框架；它不会用尚未实施的问卷虚构结论。

## 研究目标

1. 保存各时期创作者、社区管理者、比赛组织者和观众的第一手记忆；
2. 了解学习路径、常用工具、创作时间和协作方式；
3. 观察 MAD·AMV 技能与教育、自由职业和正式职业之间的关系；
4. 建立可以匿名公开的数据集、访谈目录和证据链接。

## 不应当直接推断的结论

- B站播放量不能代表整个圈子的创作者数量；
- 贴吧发帖量下降不能直接证明创作人数下降；
- 使用 AE／PR 不等于从事视频职业；
- 少数头部作者的职业路径不能代表普通创作者；
- 自愿填写的网络问卷存在明显自选偏差。

## 问卷结构

### A. 基本背景

1. 你首次接触 MAD／AMV 的年份和平台是什么？
2. 你所在的国家／地区和主要使用语言是什么？
3. 你更常使用哪些自我称呼：MADer、AMV editor、视频作者、剪辑师或其他？
4. 你参与方式有哪些：创作、观众、赛事、组织、教程、翻译、素材整理？

避免收集真实姓名、精确住址、单位和不必要的联系方式。

### B. 创作与学习

1. 最早通过什么资源学习：贴吧、B站、博客、论坛、学校、朋友、官方课程？
2. 当前使用哪些软件、插件和硬件？版本为何？
3. 一部作品通常需要多少小时？最耗时的环节是什么？
4. 是否参加 MEP、IC、比赛或团队？如何分工和交付？
5. 最常遇到的问题：素材、版权、技术、反馈、时间、设备还是平台规则？

### C. 社区与历史

1. 参与过哪些已经关闭或衰落的平台／组织？
2. 是否保存旧工程、活动海报、投稿表、网页截图或原帖备份？
3. 哪些事件是亲历，哪些来自转述？
4. 是否同意资料以实名、网名、匿名或封存方式进入档案？

每条历史陈述应附“时间、地点／平台、角色、证据、是否亲历”。

### D. 就业与技能迁移

1. MAD·AMV 经验是否帮助你获得过有偿项目、实习、升学作品集或正式工作？
2. 相关工作属于剪辑、动效、设计、三维、音频、导演、运营、教育还是其他？
3. 第一份相关机会通过什么渠道获得？
4. 哪些能力最能迁移到职业工作：节奏、叙事、软件、协作、审美、项目管理？
5. 圈内习惯与职业规范之间最大的差异是什么？
6. 是否遇到报价、合同、署名、素材授权、加班或作品集保密问题？
7. 你是否愿意继续从事相关职业？原因是什么？

### E. 可持续性

1. 什么会促使你继续或停止创作？
2. 你希望社区优先保存什么：作品、工程、教程、访谈、赛事结果还是组织档案？
3. 你是否愿意以开放许可贡献自己拥有版权的教程或资料？

## 访谈与史料核验

问卷适合观察分布，历史细节更适合半结构访谈。建议每个关键事件至少寻找：

- 一位组织者；
- 一位参与者；
- 一位当时的普通观察者；
- 一份同期页面、文件、邮件、海报或作品列表。

如果不同记忆冲突，应并列呈现版本和证据，不替读者强行消除矛盾。

## 数据发布建议

| 内容 | 推荐公开形式 |
| --- | --- |
| 问卷题目与版本 | Markdown，保留修改记录 |
| 汇总数据 | 去标识 CSV／JSON，并说明缺失值和样本偏差 |
| 访谈 | 经受访者确认的文字稿，可设置匿名或延迟公开 |
| 网页证据 | 原链接、访问日期、网页存档地址、截图说明 |
| 附件 | 校验值、文件格式、权利人和使用许可 |
| 研究结论 | 区分数据结果、研究者解释和仍待验证的假设 |

::: warning 伦理与隐私
未成年人、真实职业身份、社群冲突、收入、合同和联系方式都属于高风险信息。公开前需要明确同意、去标识化和撤回机制；“群里说过”不等于同意永久公开。
:::

## 可复用的史料条目模板

```yaml
event: 事件名称
date_start: YYYY-MM-DD
date_end: YYYY-MM-DD
platform: 平台／地点
participants: 已获同意公开的名字
claim: 需要记录的事实或回忆
evidence_type: 同期页面／文件／亲历访谈／转述
primary_url: 原始链接
archive_url: 合法网页存档
accessed_at: YYYY-MM-DD
confidence: A | B | C
rights: 资料权利与公开许可
notes: 冲突说法、缺失项和后续核验任务
```

现有长篇创作者研究见[《中国线上平台MAD创作者访谈研究》](/mad/ccopw)。它可以提供问题线索，但新调查仍需独立说明样本、招募方式、时间和伦理处理。
