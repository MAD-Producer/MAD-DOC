# MAD·AMV 术语词典

术语会随地区、时代和活动规则变化。下面给出便于检索的工作定义，不把圈内用法包装成唯一标准。

## 用语规范

- **MAD Producer**：项目维护主体的正式名称。
- **MAD DOC**：本资料项目与站点的正式名称。
- **MAD·AMV**：用于同时指涉相关创作与资料范围的站内总称，不表示 MAD 与 AMV 完全同义。
- **MAD**、**AMV**：涉及具体作品、作者、地区、活动或历史来源时，沿用该来源的自称并分别记录。
- **官方**：仅用于能够确认主体身份的版权方、平台、活动主办方或 MAD Producer 自有页面；社区整理、个人账号和转载资料不标记为官方来源。
- **规则**：平台规则、分区规则和赛事规则注明发布主体、适用范围与年份，不扩写为行业统一标准。

## 作品与风格

| 术语 | 含义 |
| --- | --- |
| MAD | 日本同人再编辑文化中的宽泛称呼，可能使用声音、动画、漫画、游戏等多种素材 |
| AMV | Anime Music Video，以动画影像与音乐构成表达的非官方音乐视频 |
| 静止画 M@D | 以漫画、插画、立绘等静态素材为主，通过合成和动画化形成作品 |
| MMV | Manga Music Video，以漫画图像为主要素材 |
| GMV | 通常指 Game Music Video；不同平台的缩写解释可能不同 |
| ASMV | Anime Story Music Video，通常强调对白、音乐与剧情化编排 |
| Animegraphy | 以一年、年代、主题或大量作品为范围的动画影像汇编 |
| Raw | 主要依靠选镜、剪辑、同步和基础处理，不以显著合成为核心 |
| FX／VFX | 强调视觉效果和合成；不同比赛对二者的区分并不一致 |
| Mograph／MG | Motion Graphics，使用图形、文字、形状和版式运动进行表达 |
| IG／INS | 源自 Instagram 发布生态的社区标签，可涵盖节奏型短 edit、Motion Design、FX、VFX、真人或游戏素材等多种方向，不是单一固定技法 |
| 风格系 | 中文社区用于概括强调视觉设计、氛围、节奏、运动或个人样式的作品；可包含长篇与短剪，不能只凭特效多少判断 |
| 短剪 | 以较短篇幅完成同步、视觉设计或情绪片段的编辑形式；是发布与制作语境，不等于低完成度，也不等同于所有“风格系” |
| MAID | 由中文 MAD 创作者提出的社区用语，指以 AI 生成素材为主要素材来源并经 MAD·AMV 方式组织的作品；不是国际通用分类 |
| Character Profile | 围绕角色或群像进行塑造 |
| Cross-over | 让不同作品中的角色、世界或事件在同一叙事中相遇 |
| Non-anime | 使用真人、电影或其他非动画影像；是否接纳取决于社区与比赛 |
| パロ／Parody | 对片头、广告、MV 或其他作品进行模仿、戏仿或结构重制 |
| Alt-Opening | 为动画制作非官方的替代片头 |

## 技术

| 术语 | 含义 |
| --- | --- |
| Sync／同步 | 画面变化与音乐节拍、旋律、歌词、情绪或结构建立对应 |
| Beat Sync | 画面切点、动作或效果与音乐节拍对应 |
| Internal Sync | 利用镜头内部已有动作与声音对应，不只依赖剪切点 |
| Over-sync | 对每个细小声音都做明显视觉对应，可能形成密集或刻意的效果 |
| Lip Sync | 重新剪辑或变形口型，使角色像是在演唱或说新内容 |
| Masking | 用遮罩分离画面区域、角色或前后景 |
| Rotoscoping／抠像 | 逐帧追踪轮廓以分离或重组对象 |
| Match Cut | 用动作、形状、构图、方向或颜色的相似性连接镜头 |
| Flow | 作品在镜头、运动、构图、情绪和音乐段落之间的连续感 |
| Time Remapping | 对素材速度进行曲线化控制 |
| 补帧 | 生成中间帧改变帧率或慢动作流畅度；错误估计会产生扭曲伪影 |
| Camera Mapping | 将平面图像分层后建立空间和虚拟摄影机运动 |
| Typography | 对歌词、对白或文本进行动态视觉设计 |
| SFX | Sound Effects，补充动作、环境、转场或冲击的声音效果 |
| TTS／声音克隆 | 由文字和参考声音生成目标音色语音的流程；公开使用可识别自然人声音前应取得授权 |
| Voice Conversion／VC | 把已有语音或演唱转换为另一音色，同时尽量保留原表演的节奏、音高和语气 |
| RVC | Retrieval-based Voice Conversion，一类基于检索特征的语音转换框架；常用于变声和歌声转换，不等于 TTS |
| 声源分离 | 从混合音轨估计对白、人声、鼓、贝斯或伴奏等分量；结果不是官方分轨，通常存在残留与伪影 |
| AI 生成合成内容标识 | 对 AI 生成或合成的文字、图片、音频、视频等添加可感知标识或文件内隐式信息；具体义务按发布地和平台规则执行 |

## 合作与比赛

| 术语 | 含义 |
| --- | --- |
| MEP | Multi-Editor Project，多位编辑分别制作音乐片段，再由统筹整合 |
| Collab | 泛指合作作品，不一定按音乐等分，也不一定遵循 MEP 流程 |
| IC | Iron Chef，限时、限题或限素材创作，有时采用对战形式 |
| 大赛 | 通常有较长征稿期、入围／排名和多个奖项的综合比赛；并不是具有统一门槛的法定等级 |
| 表演赛 | 以节庆、交流或展映为主，通常不设置正式总排名和奖金 |
| 曲包 | IC 开赛时由主办方提供的歌曲集合，可能按 Action、Dance、Drama 等分类并限制跨组使用 |
| 入围 | 作品通过初审或筛选，进入展播、终审或排位阶段；不等于已经获得名次 |
| 初审／终审 | 初审多负责规则与入围筛选，终审多负责排名和奖项；具体权重由当届规则决定 |
| 一稿多投 | 同一作品同时或先后参加多个赛事；多数比赛会限制，但范围和例外需看当届规则 |
| 随交随投 | 主办方确认收稿后，作者即可自行公开作品；与等待官方合集后再发布相对 |
| Loop／循环 | 重复已经编辑好的片段；比赛通常禁止用循环凑足正片时长 |
| Beta | 正式发布前用于征求意见的测试版本 |
| Beta Tester | 对测试版本提出节奏、叙事、技术和可读性意见的人 |
| Coordinator | MEP／合作企划的统筹者，负责规则、分段、交付和整合 |
| Track | MEP 中分配给一位或一组作者的音乐片段 |
| Intro／Outro | 作品或合作企划的片头、片尾和署名段落 |
| Deadline | 投稿或交付截止时间；比赛通常还会规定时区 |
| Premiere | 首次公开发布或展映 |

## 中文社区常见说法

| 术语 | 含义与注意事项 |
| --- | --- |
| MADer | MAD 创作者的社区称呼 |
| 三剪 | 对其他创作者已经完成的二创视频再次简单剪辑；通常具有明显署名与版权风险 |
| 燃向 | 以热血、动作和高能量体验为主的宽泛中文标签 |
| 泪燃 | 同时追求情感累积与动作／高潮释放的社区标签 |
| 剪辑感 | 对节奏、镜头选择、运动方向和视听衔接的综合感受，不是单一技术指标 |
| 素材利用率 | 素材选择是否服务主题，并不等于“使用镜头数量越多越好” |
| 同质化 | 作品在选曲、素材、结构、效果或模板上高度重复 |
| 卡点 | 让镜头或效果在节拍点发生变化；同步的一种基础形式 |
| 误解系 | 通过重排原作关系和情节，让观众理解出不同故事；边界和称呼主要来自中文社区 |
| 仿作 | 为学习而复现某作品的效果或流程；公开时应标明参考，不应冒充原创 |
| 长篇 MAD·AMV 圈层 | 以 Bilibili 投稿、团队和赛事为重要节点，常围绕完整歌曲或较长段落组织作品的大陆创作社群；属于圈层观察，不是作品类型 |
| 风格系短剪圈层 | 以短篇 edit、个人样式和短视频／即时社群传播为重要特征的大陆创作社群；与长篇圈层有交叉，但社交网络和评价语境已明显分化 |

## 容易产生误会的词

- **“特效”**：既可能指简单转场，也可能指复杂合成。讨论时最好写明具体方法。
- **“原创”**：可以指原创剪辑表达，也可以指原创素材；两者的权利范围不同。
- **“无版权”**：通常是错误说法。更准确的表述是公共领域、特定开放许可、已获授权或免版税许可。
- **“官方”**：原作版权方、平台账号、活动主办方、社区管理者是不同主体。
- **“规则”**：比赛规则只约束该活动，平台规则只约束该平台；它们都不是普遍定义。
