# MAD·AMV 术语表

::: tip 要点
- 按用途分为七组：作品与类型、内容标签、素材、技术、声音与 AI、合作与比赛、中文社区说法。
- 每个词只给最常见的用法。同一个词在不同社区、年代或比赛里含义可能不同，比赛用语以当届规则为准。

## 作品与类型

| 术语 | 含义 |
| --- | --- |
| MAD | 日本同人文化中对“重新剪辑现成素材做出新作品”的宽泛称呼，素材可以是声音、动画、漫画、游戏 |
| AMV | Anime Music Video，用动画画面配合音乐重新剪辑的非官方音乐视频 |
| MAD·AMV | 中文平台对两者的合称，也是 B站分区名；不表示二者完全相同 |
| 静止画 M@D | 以漫画、插画、立绘等静态图为主，靠合成和动画化做成的作品 |
| M@D | MAD 的变体写法，静止画圈常用；“@”不代表某种技术 |
| MMV | Manga Music Video，以漫画为主要素材 |
| GMV | Game Music Video，以游戏画面为主要素材 |
| ASMV | Anime Story Music Video，用对白、环境声和音乐做成剧情短片或预告片式结构 |
| FMV | 在 Wuyi无疑的分类里指 Fan-made MV，范围比 AMV 宽；别处也可能指 Full Motion Video |
| Animegraphy | 以一年、一个年代或一个主题为范围的大量动画镜头汇编 |
| 动画系／静止系／风格系 | 中文社区的三大常用分类，见[作品类型与分类](/mad/classification) |
| 误解系 | 重排原作对白和情节，让观众看到不同故事的作品 |
| 复合 MAD | 又称“出招表”：把相似动作连续接成一套，配合强节奏音乐。不是“混合素材”的意思 |
| iMADs／im@ds | 以《偶像大师》系列为素材的 MAD；这里的 i 不是 Instagram |
| 手书 | 作者自己绘制的二创动画 |
| MAID | 中文 MAD 作者提出的说法，指以 AI 生成素材为主的 MAD；不是国际通用分类，见[AI 辅助与 MAID](/tools/ai) |

## 内容标签

| 术语 | 含义 |
| --- | --- |
| Action | 突出动作的连贯、力度和速度 |
| Dance | 以舞蹈动作和音乐律动为中心 |
| Comedy／Humor | 制造明确的笑点、反差或恶搞 |
| Fun／Play | 轻快好玩，不一定靠笑点 |
| Drama | 通过剪辑重新组织剧情和人物冲突 |
| Romance | 以人物关系和恋爱情绪为中心 |
| Sentimental | 友情、成长、怀旧、离别等情绪，冲突比 Drama 弱 |
| Character Profile | 集中表现一个角色或群像 |
| Story | 以事件和因果为骨架，没看过原作也能大致看懂 |
| Psyche | 迷幻、意识流、心理压迫感 |
| Horror／Dark | 恐怖、不安，或整体阴暗压抑 |
| Cinematic | 电影预告式的段落、配乐和音效 |
| Trailer | 把素材剪成预告片，可以给不存在的电影做“伪预告” |
| Candy | 甜美明亮的视觉方向，常用色块、装饰图形和动态图形 |
| Upbeat | 情绪高扬、明快 |
| Rhythm & Beat | 主要看点是画面和音乐律动的持续对应 |
| Ecchi | 带性感或成人暗示的内容；平台和比赛审核尺度不同 |
| Cross-Over | 让不同作品的角色、世界在同一叙事里相遇 |
| Parody／パロ | 对片头、广告、MV 等进行可辨认的模仿或戏仿 |
| Alt-Opening | 用另一部作品的素材重做某个动画片头 |
| BGA | Background Animation，为音游或音乐活动的曲目做的背景影像 |
| CM | 宣传短片；在 MAD 圈常指比赛、团队的告知视频 |
| PV | Promotion Video（宣传片），有时也指 Preview（预告） |
| MTV／MV | 音乐影片；早期分类用 MTV 区分官方作品 |

## 素材

| 术语 | 含义 |
| --- | --- |
| Raw | 主要靠选镜、剪辑和同步，不以明显的合成为核心 |
| Non-Anime | 主要素材不是日本动画，例如欧美动画、真人影视、游戏 |
| Original Animation | 作者自己画或做的动画镜头 |
| 生肉／无字幕素材 | 没有烧录字幕的原始片源；获取方式要合法 |
| 素材利用率 | 镜头是否服务于主题，不是用得越多越好 |

## 技术

| 术语 | 含义 |
| --- | --- |
| Sync（同步） | 画面变化与音乐的节拍、旋律、歌词或情绪对应 |
| 卡点／Beat Sync | 镜头或效果在节拍点上变化，最基础的同步 |
| Internal Sync | 用镜头内部已有的动作对上声音，而不只靠切点 |
| Over-Sync | 对很多细小声音都做明显的视觉对应；太密会影响观感 |
| Lip Sync | 让角色口型对上新的歌词或台词 |
| Match Cut | 利用动作、形状、构图或颜色的相似连接两个镜头 |
| Flow | 镜头、运动、情绪和音乐段落之间的连续感 |
| Time Remapping | 用曲线控制素材速度 |
| 补帧 | 计算中间帧做慢动作或提高帧率；遮挡和快速运动处容易扭曲 |
| Masking（遮罩） | 分离画面中的区域、角色或前后景 |
| Rotoscoping（抠像） | 逐帧描出轮廓，把对象分离出来 |
| Camera Mapping | 把平面图分层后建立空间，用虚拟摄像机运镜 |
| FX | 中文资料里偏向字块、色层、缩放等节奏效果 |
| VFX | 偏向重新构图、跟踪、抠像、三维和画面合成 |
| MG／Motion Graphics | 用图形、文字、形状和版式运动构成画面 |
| GFX | 封面、海报等平面设计，也指做这些设计的人 |
| Typography | 歌词、对白等文字的动态设计 |
| Kinetic Typography | 文字的位置、大小、字形随节奏变化，文字本身承担表达 |

## 声音与 AI

| 术语 | 含义 |
| --- | --- |
| SFX | 音效：撞击、环境、转场等 |
| 声源分离 | 从混合音轨中估算出人声、鼓、伴奏等；结果不是官方分轨，会有残留 |
| TTS／声音克隆 | 输入文字和参考声音，生成目标音色的语音 |
| VC（Voice Conversion） | 把已有的说话或演唱换成另一种音色，保留原来的语气和节奏 |
| RVC | 一种常用的语音转换框架；不是 TTS |
| 歌声合成 | 输入歌词和音符直接合成歌声，例如 DiffSinger |
| AI 生成内容标识 | 对 AI 生成或合成的内容加上可见标识或文件内信息；中国大陆自 2025-09-01 起强制 |

## 合作与比赛

| 术语 | 含义 |
| --- | --- |
| MEP | Multi-Editor Project：多位作者各做一段（Track），再由统筹整合 |
| Collab | 合作作品，不一定按段落分工 |
| IC | Iron Chef：限时、限题或限素材的创作比赛，有时是对战形式 |
| 曲包 | IC 开赛时主办方给的歌曲集合，常按类型分组 |
| 大赛 | 征稿期长、有入围和多个奖项的综合比赛 |
| 表演赛 | 以展映和交流为主，通常不设总排名 |
| 入围 | 通过初审，进入展播或终审；不等于获奖 |
| 初审／终审 | 初审筛规则和质量，终审定名次 |
| 一稿多投 | 同一作品参加多个比赛；多数比赛限制 |
| 随交随投 | 主办方确认收稿后，作者可以自行发布 |
| Loop（循环） | 重复已剪好的片段；比赛通常禁止用它凑时长 |
| Coordinator／主催 | MEP 或合作企划的统筹人 |
| Track | MEP 中分给一位作者的音乐片段 |
| Beta／Beta Tester | 正式发布前的测试版，以及给测试版提意见的人 |
| Intro／Outro | 片头、片尾和署名段落 |
| Deadline | 截止时间；注意比赛使用的时区 |
| Premiere | 首次公开或首映 |

## 中文社区说法

| 术语 | 含义 |
| --- | --- |
| MADer | MAD 创作者 |
| 三剪 | 把别人做好的二创视频再简单剪一遍发布；有署名和版权问题，比赛不接受 |
| 仿作 | 为学习而复刻某作品的效果；公开时要标明参考对象 |
| 燃向 | 热血、动作、高能量 |
| 泪燃 | 先积累情感，再在高潮释放 |
| 剪辑感 | 对节奏、选镜、运动方向和衔接的综合感受 |
| 同质化 | 选曲、素材、结构或效果高度雷同 |
| 短剪 | 篇幅很短的作品形式，不代表完成度低 |

## 容易误会的词

- **特效**：可能指简单转场，也可能指复杂合成，讨论时最好说清具体做法。
- **原创**：可能指剪辑表达是原创，也可能指素材是原创，两者的权利完全不同。
- **无版权**：通常是错误说法。准确的说法是公共领域、某种开放许可、已获授权或免版税。
- **官方**：版权方、平台、比赛主办方、社区管理者是不同的主体。
- **规则**：比赛规则只管这个比赛，平台规则只管这个平台。
