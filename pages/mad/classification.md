# MAD·AMV 分类方法

没有一套分类法能同时覆盖日本 MAD、欧美 AMV、中文平台分区和所有比赛。MAD DOC 采用多维字段记录作品，避免用单一互斥分类树覆盖不同语境。

本站的主要讨论对象是**以 Bilibili 为发布、赛事和交流中心的中国大陆 MAD·AMV 圈层**。日本静止画 MAD、欧美 AMV 与风格系短剪资料用于解释来源和交叉影响，不取代这一主体范围。

## 五维分类

### 1. 素材媒介

| 标签 | 说明 |
| --- | --- |
| 动画 | 电视动画、剧场版、OVA、原创动画等动态影像 |
| 漫画／插画 | 漫画分镜、立绘、同人图、视觉小说素材 |
| 游戏 | 游戏过场、实机画面、角色模型或游戏宣传素材 |
| 真人／非动画 | 电影、剧集、实拍、广告、纪录影像 |
| 原创 | 作者自行绘制、拍摄、建模或生成并拥有使用权的素材 |
| 混合 | 两种以上媒介共同构成，且都承担重要表达作用 |

### 2. 表达目的

| 标签 | 典型目标 |
| --- | --- |
| Action | 强调动作连贯、力度、速度和段落推进 |
| Dance | 以舞蹈动作、音乐律动和身体节拍为中心 |
| Fun／Comedy | 制造笑点、反差、恶搞、模仿或轻松氛围 |
| Drama／Romance | 建立人物关系、冲突、情绪和故事线 |
| Character Profile | 围绕一个角色或群像塑造形象 |
| Psyche／Horror | 追求心理压迫、诡异、不安或恐怖体验 |
| Sentimental | 以怀旧、治愈、离别、成长等情感为中心 |
| Experimental | 以形式、媒介或感知实验为主要目的 |

这些标签可以共存。例如一部作品完全可以同时是“Action + Character Profile + Sentimental”。

### 3. 制作技术

| 标签 | 判断重点 |
| --- | --- |
| Raw／纯剪辑 | 主要依靠镜头选择、排序、变速和基础处理形成表达 |
| FX／VFX | 大量使用视觉特效、合成、跟踪、抠像、粒子或三维 |
| Motion Graphics | 图形、文字、形状和版式运动承担主要视觉表达 |
| Typography | 歌词、对白或文字的动态设计是核心元素 |
| Lip Sync | 重新组合口型，使角色像是在演唱或说新台词 |
| Match Cut | 利用构图、动作、颜色或形状相似性完成镜头匹配 |
| Masking／Rotoscoping | 通过遮罩或逐帧分离人物与背景 |
| Frame Interpolation | 通过补帧或重定时改变动作速度与流畅度 |
| Original Animation | 在既有素材之外加入作者自行制作的动画 |
| Color Design | 通过统一或重构色彩建立场景联系与情绪 |

“Raw”不等于低技术，“FX”也不等于更高级。它们只描述作品将主要精力放在哪里。

### 4. 组织方式

| 标签 | 说明 |
| --- | --- |
| Solo | 单人主导完成 |
| Collab | 多位作者合作，形式和分工不固定 |
| MEP | Multi-Editor Project，通常按音乐段落分配给多位编辑并统一整合 |
| IC | Iron Chef，在限定时间、素材或主题下完成的创作／对战形式 |
| Studio／Team | 以稳定团队或工作室名义发布 |

### 5. 发布语境

- **Contest Entry**：为指定比赛制作，必须同时记录该届规则。
- **Festival／Event**：节庆、周年、合作企划或展映作品。
- **Trailer／PV／CM**：模仿或重构预告、宣传片、广告形式。
- **Parody／パロ**：对原作、片头、MV 或广告进行明确的模仿和戏仿。
- **Alt-Opening／Alt-Ending**：为作品重制非官方片头或片尾。
- **BGA／MV**：作为音乐背景动画或音乐视觉化内容。

## 常见“大类”如何使用

### 动画系

指主要素材为已经存在的动态动画镜头，作者通过选镜、重排、同步、声音和合成建立新表达。它可以只使用一部作品，也可以跨多部动画选材。

动画系常见的制作重心包括：

- **纯剪辑／Raw**：用镜头内容、动作方向、切点、变速和段落结构完成表达；
- **剧情／情感**：重组原作事件或人物关系，建立完整情绪推进；
- **动作／舞曲**：让动作、摄影机运动和剪切与音乐节拍、力度对应；
- **FX／VFX**：在剪辑之外大量加入图形、文字、遮罩、跟踪和重新合成；
- **ASMV**：使用对白、环境声、字幕和音乐构成电影预告式或剧情短片式结构；
- **多素材 AMV**：从多部动画中选择镜头，用共同主题、动作或视觉关系统一成片。

“动画系”只说明主要素材是动态动画，不表示作品一定是纯剪辑，也不是 AMV 的完整同义词。

### 静止系

主要以漫画、插画、立绘等静态素材，通过镜头运动、分层、遮罩、变形、排版和合成建立时间性。常见相关称呼包括：

- **静止画 M@D**：日本及中文社区常见写法。
- **MMV**：Manga Music Video，通常强调漫画图像与音乐。
- **漫画系**：漫画格、对白框和网点是主要素材，常通过拆格、补图和重新排版控制阅读顺序。
- **GAL／视觉小说系**：使用角色立绘、事件 CG、背景和文字信息，通过表情差分、分层和镜头运动建立演出。
- **轻小说／插画系**：素材数量通常较少，更依赖构图延展、文字、氛围和原创补充设计。

静止系的“动”通常来自以下工作：

1. 把人物、头发、衣物、前景和背景拆成可独立运动的层；
2. 修补被人物遮挡的背景或缺失画面；
3. 用 2.5D／三维空间、虚拟摄影机、景深和光影建立镜头；
4. 重组漫画格和文案，使观众按作者设计的顺序阅读；
5. 通过形变、粒子、逐帧动画或原创绘制补充动作。

因此，静止系不是“放几张图片加转场”，也不能只用素材是静态还是动态评价工作量。

### 风格系

“风格系”不是稳定的国际分类。中文社区常用它描述视觉设计、氛围、节奏或形式感高于明确叙事的作品，尤其常见于短篇 edit 和 IG／INS 传播语境。

它可能包含：

- 通过拉镜、抖动、旋转、模糊和变速建立连续运动；
- 用色块、图形、文字、调色和界面元素形成个人视觉语言；
- 对鼓点、音色、歌词和细小声音做多层同步；
- 使用动画、漫画、游戏或真人素材，不由单一素材类型决定；
- 以数秒至一分钟的高密度片段为主，也可以发展为完整比赛稿。

风格系不是“特效很多”的同义词。只有预设堆叠而没有稳定的运动逻辑、构图和节奏设计，并不能自动形成可辨认的风格。

### 特效系

通常指合成、运动图形或视觉效果占比显著的作品。它与 FX／VFX 接近，但边界取决于社区或比赛。

- **FX**在部分中文资料中偏向字块、纯色层、缩放、图形和节奏效果；
- **VFX**更常指重新构图、抠像、跟踪、三维空间、粒子和画面级合成；
- **Motion Graphics**以文字、形状、版式和抽象图形运动为主；
- **GFX**在圈内还可能专指封面、海报等平面视觉设计。

这些词可以重叠，也不存在公认的技术等级。特效数量不能替代主题、剪辑和整体设计。

### 混合系

混合系指动画、漫画、游戏 CG、立绘或其他媒介共同承担主要表达，而不是偶尔插入一两帧不同素材。常见做法包括动画镜头与漫画格交替、动态角色与静态背景重组，或用多个媒介表现同一角色和时间线。

归类时可记录各类素材的大致占比和功能。比赛可能要求作者按主要素材选择动画或静止赛道，也可能设置独立混合赛道。

### GMV

GMV 通常指 Game Music Video，主要使用游戏实机、过场动画、宣传片或角色模型。若素材几乎全部是动画化的游戏过场，它在视觉上可能接近动画 AMV；若以实机战斗、竞速或电竞画面为主，则更接近游戏剪辑。

不同 MAD 比赛对 GMV 的接收范围差异很大，不能因为标题写有“AMV”就默认可以进入动画赛道。

### 特摄、真人与 Non-Anime

特摄剪辑使用特摄剧、电影或相关衍生影像；Non-Anime 则是更宽的非日本动画素材标签，可以包含欧美动画、真人影视和其他影像。它们与 MAD 的再编辑方法可以相同，但 Bilibili 分区及比赛是否接收，需要分别核对。

### 误解系

误解系通过重排对白、表情、事件顺序和人物关系，让既有素材呈现与原作不同的新故事。它不是简单概括原剧情，而是有意识地建立另一套因果关系。

误解系尤其依赖观众能否看懂新设定、镜头之间是否建立因果，以及对白和声音是否支持新叙事。仅仅打乱时间线或让角色跨作品同框，不一定构成完整误解叙事。

### 手书、原创动画与 PV

- **手书**通常指作者自行绘制的二次创作动画，可能模仿原作片头、歌曲 PV 或独立演出；
- **原创动画**强调画面素材由作者制作，未必属于使用既有素材再编辑的 MAD；
- **PV／Promo**以宣传歌曲、作品、比赛或企划为目的，是发布功能而非固定视觉风格。

它们与 MAD·AMV 经常交叉，但部分比赛会明确排除纯手书、原创 CG 或宣传 PV，原因通常是收稿范围和评审基准不同，并不表示这些形式没有创作价值。

## Wuyi无疑《MAD的分类》

Wuyi无疑在 2019 年发布的《MAD的分类》中，将“分类”和“Tag”分为两个部分。以下按原文层级列出，术语说明作了简化，未改写其基本结构。

### Part I：分类

| 一级分类 | 二级分类 | 下级类型 |
| --- | --- | --- |
| 动画系 MAD（AMV） | Raw | Action、Dance、Fun／Comedy、Drama／Romance、Psyche／Horror |
| 动画系 MAD（AMV） | VFX | 以大幅度重新构图和视觉合成为主要表现方式 |
| 动画系 MAD（AMV） | FX | 剪辑与大量图形、色块、缩放等效果共同服务于节奏 |
| 静画系 MAD | MMV | 以漫画为主要素材的 Manga Music Video |
| 静画系 MAD | 静止系 M@D | 强调静态素材、文案编排及分镜之间的联系 |
| 混合系 MAD | — | 混合使用 ACGN 等不同媒介素材 |

原文对 Raw 之下的表达类型作了进一步说明：

| 类型 | 原文要点的本地摘要 |
| --- | --- |
| Action | 强调动作、力量和流畅节奏 |
| Dance | 强调律动、节奏和镜头运动 |
| Fun／Comedy | 以趣味、喜剧和观众反应为主要目标 |
| Drama | 通过剪辑重新组织剧情与分镜意义 |
| Romance | 以人物关系和浪漫情绪为中心 |
| Psyche | 以迷幻、意识感和创造性画面为主要特征 |
| Horror | 通过氛围、悬念与不安感建立恐怖体验 |

### Part II：Tag

原文将其他常见称呼归入 Tag，并明确指出一部作品可以同时具有多个标签：

| 范围 | 原文列出的标签 |
| --- | --- |
| 叙事与人物 | ASMV、Character Profile、Story、Sentimental、Cinematic、Dark、Trailer |
| 类型与情绪 | Candy、Comedy／Humor、Ecchi、Play／Fun、Rhythm & Beat、Upbeat |
| 素材与媒介 | FMV、Manga、Non-Anime、Original Animation、iMADs、复合 MAD |
| 视觉与声音技术 | GFX、Kinetic Typography、MG、Over-Sync、Lip Sync、SFX、补帧 |
| 形式与发布 | Alt-Opening、BGA、CM、MTV、PV／Promo／Preview、Parody／パロ |
| 合作方式 | Collab、MEP |
| 音乐相关 | Instrumental、RAP、Trap |
| 平台衍生 | INS／ig、Vine |
| 其他写法 | Cross-Over、M@D |

### Part II 标签逐项解释

以下说明展开原文列出的全部标签。它们描述的对象并不处于同一层级：有些是表达目的，有些是素材、技术、音乐、合作方式或发布平台。入库时可以同时使用多个标签。

#### 叙事、人物与气氛

| 标签 | 含义 | 与相近标签的区别 |
| --- | --- | --- |
| ASMV | Anime Story Music Video。通常保留或重新组织对白、字幕、环境声和音乐，形成接近预告片或剧情短片的叙事 | 不等于所有剧情向 AMV；它通常更依赖对白与电影化声音结构 |
| Character Profile | 集中表现单个角色或群像的性格、经历、关系和变化 | 可以忠于原作，也可以通过剪辑提出新的角色解读 |
| Story | 以事件发展和因果关系为骨架，让没有看过原作的观众也能大致理解作品讲了什么 | 不要求彻底改写原剧情 |
| Sentimental | 以友情、成长、怀旧、离别、治愈等情绪体验为主 | 通常比 Drama 少一些强烈冲突，也不必以恋爱关系为中心 |
| Cinematic | 使用电影预告式的段落、史诗音乐、对白、环境声和音效建立电影化气氛 | 描述呈现方式，不代表素材来自电影 |
| Dark | 从题材、色彩、声音到结构整体偏阴暗、压抑或危险 | 可以与 Horror、Psyche、Drama、VFX 同时出现 |
| Trailer | 把素材重新组织为预告片，常见片名、对白、悬念、节奏升级和结尾信息卡 | 可能为不存在的影片制作“伪预告”，也可能替原作重制预告 |

#### 情绪、节奏与内容取向

| 标签 | 含义 | 使用时注意 |
| --- | --- | --- |
| Candy | 偏甜美、明亮、活泼的视觉方向，常使用角色静态图、色块、装饰图形和 Motion Graphics | 原文将其概括为“甜系”，常与 FX、Dance、Upbeat 重叠 |
| Comedy／Humor | 以明确笑点、反差、误会、恶搞或节奏设计使观众发笑 | 比泛指轻松愉快的 Fun 更强调“笑点” |
| Ecchi | 带有性感、挑逗或成人暗示的内容标签 | 平台与比赛审核尺度差异很大，不应把标签当作可过审保证 |
| Play／Fun | 以轻快、好玩、脑洞或互动感为主，不一定依靠传统喜剧笑点 | 可与游戏化结构、猜角色、Dance 等结合 |
| Rhythm & Beat | 主要吸引力来自音乐律动和画面动作的持续对应，让观众感到可以随节拍摆动 | 与 Dance 接近，但未必真的使用舞蹈镜头 |
| Upbeat | 整体情绪高扬、明快、有活力，常见于 Dance、Fun 和青春群像 | 描述情绪和音乐能量，不是固定剪辑技法 |
| Comedy／Fun | 比赛中常被合并成一个大类，实际可分别理解为“制造笑点”和“传达快乐” | 分类时可根据作品目标细分，也可沿用赛事合并写法 |

#### 素材与媒介

| 标签 | 含义 | 使用时注意 |
| --- | --- | --- |
| FMV | 原文使用 Fan-made MV，指比 Anime Music Video 更宽的非官方音乐影像，可包含非日本动画或其他影像 | 其他社区也可能把 FMV 解释为 Full Motion Video，引用时必须写明语境 |
| Manga | 使用漫画页、漫画格或漫画角色图像 | 只要包含漫画不一定就是 MMV；应看漫画是否为主要素材 |
| Non-Anime | 主要素材不属于日本动画，例如欧美动画、真人影视或游戏画面 | 与 FMV、GMV 有交叉，比赛未必接收 |
| Original Animation | 作者自行绘制或制作动画镜头，并把它们加入 MAD·AMV | 应区分“原创动画素材”和“对既有素材的原创剪辑” |
| iMADs／im@ds | 以《偶像大师》（THE iDOLM@STER）系列为素材或文化中心的 MAD 称呼 | 这里的字母 i 不是 Instagram，也不是 AI |
| 复合 MAD | 又常被称作“出招表”；把相似动作或姿态连续接成一套动作组合，并与强节奏音乐同步 | 原文所说“复合”不是泛指混合素材，与“混合系 MAD”不是同一个概念 |

#### 视觉、文字与声音技术

| 标签 | 含义 | 判断重点 |
| --- | --- | --- |
| GFX | Graphics FX。常指作品封面、海报或单帧视觉设计，也可指负责该设计的作者 | 在视频正文中使用时，应说明是平面设计还是动态合成 |
| Kinetic Typography | 让文字的位置、大小、旋转、字形和出现节奏随时间变化，使文字本身承担情绪和节奏表达 | 不只是把字幕加上入场动画 |
| MG／Motion Graphics | 以形状图层、文字、图标、版式和抽象图形运动建立画面 | 可以作为整片风格，也可以只用于片头和局部桥段 |
| Over-Sync | 同时使用切点、内部动作、口型、效果、文字和声音等多层同步，使画面密集对应音乐细节 | 不是同步越多越好；过密对应可能损害可读性和段落层次 |
| Lip Sync | 通过选镜、剪切、变速或变形，让人物口型与新的歌词或对白对应 | 需要同时检查音节、开合口型、表情和镜头连续性 |
| SFX | Sound Effects。补充撞击、环境、转场、动作和空间声音，强化画面质感或电影感 | 原作音效、素材库音效和作者自制音效应分别记录来源 |
| 补帧 | 估计中间帧以制作慢动作、变速或高帧率输出 | 动漫重复帧、快速遮挡和闪烁场景容易出现果冻、重影和错误线条 |
| FX／VFX | FX 常偏重字块、色层、缩放和节奏效果；VFX 常偏重重新构图、跟踪、抠像和画面合成 | 这是原文的工作区分，不是所有比赛或作者都按同一方式使用 |

#### 发布形式与仿作关系

| 标签 | 含义 | 使用时注意 |
| --- | --- | --- |
| Alt-Opening | 用另一部作品的素材重制或替换某个动画片头的镜头结构、音乐和演出 | 应同时标明被模仿的片头与使用的素材作品 |
| BGA | Background Animation，常见于音游或音乐活动，为一首曲目制作的背景影像 | BGA 可以独立观赏，但创作目的首先是服务指定音乐 |
| CM | Commercial／宣传短片。在 MAD 圈也常指比赛、团队或活动的告知视频 | 与完整比赛稿不同，重点是信息传达和吸引参与 |
| MTV | 原文用来区分官方制作的音乐影片与非官方音乐系 AMV | 当代更常直接写 MV；不建议仅凭“官方／非官方”机械区分 |
| PV／Promo | Promotion Video，宣传作品、音乐、活动或企划的影片 | 重点是推广对象，而非一定采用某种画面风格 |
| PV／Preview | Preview，预告或先行片段；在比赛宣传中可能与 CM 混用 | 同一个缩写有两种展开，引用时应写出全称 |
| Parody／パロ | 对片头、广告、MV、预告或流行视频的结构和演出进行可辨认的模仿、戏仿或重制 | 致敬不自动排除抄袭争议；比赛对仿作的接受程度不同 |

#### 合作、音乐与平台来源

| 标签 | 含义 | 使用时注意 |
| --- | --- | --- |
| Collab | 两人或少数作者共同完成一部结构连贯的作品，分工不一定按音乐段落切开 | 应记录实际参与者和分工 |
| MEP | Multi-Editor Project。多位作者分别制作指定 Track，再由主催统一片头、转场和输出 | MEP 的关键是分段统筹，不只是“人多” |
| Instrumental | 使用无人声的器乐曲或纯音乐 | 描述音乐，不说明作品属于 Action、Drama 或其他表达类型 |
| RAP | 使用说唱音乐，常利用密集歌词做 Lip Sync、Typography 或快速同步 | 不是只要歌曲含一段说唱就必须标注 |
| Trap | 使用 Trap 音乐及其重拍、切分和音色特征，早期短 edit 中常与 IG 风同步技法结合 | 属于音乐与历史语境标签，不等于某套固定预设 |
| INS／IG | 源自 Instagram 的短篇 edit 生态，强调节奏、设计、运动和个人样式 | 不是单一技法，详细分类见下文 |
| Vine | 源自已停止服务的短视频平台 Vine，常指短小、循环、快速放缩和形状动画明显的 edit | 现主要作为历史标签保留 |
| M@D | 日本及中文社区常见的 MAD 变体写法，尤其常见于静止画 M@D | “@”不是一个独立技术分类，也不能据此判定素材一定静止 |

这套分类的价值在于保留了 2019 年中文 MAD·AMV 社区常用的大量检索词。使用时需要同时注意：

1. 作者明确说明分类更偏欧美 AMV 社区；
2. 分类、素材、风格、技术、活动方式和平台来源存在层级混合；
3. 标签并不互斥；
4. 部分术语在不同站点、时期和活动中具有不同解释。

MAD DOC 因此并列保留原始分类表与前述五维分类，不以其中任何一套覆盖作者自我标注或赛事规则。

## IG／INS

IG 是 Instagram 的常用简称。中文 MAD·AMV 社区中的“IG 风”来自创作者在 Instagram 发布的短篇 edit／AMV，但它并不是一种边界固定的单一技术风格。

Wuyi无疑的分类表把 **INS／ig** 作为 Tag，概括为短小、可循环、偏意识流、重视设计与节奏的作品。2019 年 NEW EDITORS CON 的说明则采用更宽的范围，将 IG 视为平台中多种短篇编辑风格的集合，并列举了以下常见方向：

| 方向 | 常见表现 |
| --- | --- |
| 节奏型短 edit | 拉镜、抖动、曝光、调色、模糊、变速和密集同步，强调流畅与张力 |
| 混合型 | 将 IG 常见的模糊、抖动和节奏处理与较长篇幅剪辑、三维场景结合 |
| Motion Design | 以平面设计、文字动画、排版和图形运动构成画面 |
| Candy／FX | 以明亮图形、色块、形状动画和效果设计为主要特征 |
| Pulse／脉冲 | 使用高频闪烁、跳切和强烈视听刺激 |
| Celebrity Edit | 使用真人明星或偶像素材，常见变速与流畅运动衔接 |
| GMV Edit | 使用游戏实机、过场或竞技片段进行短篇编辑 |
| VFX／3D | 在三维空间中组织镜头、文字和场景，强调摄影机运动与空间设计 |

上述方向来自特定作者对当时 Instagram 编辑生态的观察，不构成平台官方分类。作品登记时，“IG／INS”可作为发布文化或社区风格标签，同时继续记录实际素材、表达目的和制作技术。

## 中国大陆的两类创作圈层

这里讨论的是**创作者社交网络与发布生态**，不是把所有作品重新分成两个互斥类别。进入 2020 年代后，中国大陆的 MAD·AMV 创作者已经明显分化为两个相对独立、仍有交叉的圈层：

| 观察维度 | Bilibili 长篇 MAD·AMV 圈层 | 风格系短剪 AMV 圈层 |
| --- | --- | --- |
| 主要发布与存档 | 以 Bilibili 的视频投稿、合集、团队账号和赛事页面为中心 | 以短视频平台、即时社群和作者个人账号为中心，也会把作品转发至 Bilibili |
| 常见篇幅 | 多按完整歌曲或主要段落组织，常见约 2—5 分钟；ASMV 可更长 | 常见数秒至 1 分钟，也存在 1—3 分钟的风格系比赛稿 |
| 作品重心 | 选镜、叙事、情绪推进、完整结构、动画／静止素材再组织 | 同步、速度、拉镜、抖动、转场、图形、调色、短时视觉密度和个人样式 |
| 社群入口 | MAD 团队、赛事、Bilibili 作者、MAD吧旧资料与教程 | 风格标签、短剪教程、作者交流群、移动端或 AE 工程交流 |
| 常见评价语境 | 主题、镜头语言、素材利用、结构、技术完成度与赛事规则 | 流畅度、力度、同步、视觉设计、效果完成度与可辨识风格 |
| 资料保存风险 | 页面相对适合长期引用，但活动附件和旧稿仍可能失效 | 作品短、跨平台搬运多、账号迁移快，原始作者与首发时间更难追溯 |

这一区分有三组可核验证据：

1. 2024 年完成的[中国线上平台 MAD 创作者访谈研究](/mad/ccopw)包含 69 次半结构化访谈。论文把以 Bilibili 为中心的 MAD 社群与 Instagram／中国 TikTok 上的 IG 风格创作者分开讨论，并记录了不同的社群关系、教程和商业实践。
2. 2019 年 [NEW EDITORS CON 的 IG 科普](https://www.bilibili.com/opus/215518138904040334)把 IG 理解为 Instagram 中多种短篇 edit 的集合，而不是 Bilibili 长篇 MAD 的一个固定技法分支。
3. 2026 年 [IMAC FUN#4 规则](https://www.bilibili.com/opus/1203002472552988705)分别规定动画系 AMV 为 2—5 分钟、静止系为 1 分 30 秒—5 分钟、风格系及其他 MAD 为 35 秒—3 分钟。单届赛事规则不能代表全行业，但说明组织者已经在实际征稿中区分这些生产语境。

“相对独立”不等于没有交流。长篇作品可以大量使用风格系技术，短剪作者也会参加 Bilibili 比赛或制作长篇作品；Bilibili 同样存在大量短剪投稿。登记作者和作品时，应分别记录**发布平台、常用篇幅、社群自称与实际技术**，不应根据时长替作者强行归圈。
