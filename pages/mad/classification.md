# MAD·AMV 作品类型与分类

::: tip 要点
- 中文社区最常用的大类是**动画系、静止系、风格系**，另有特效系、混合系、GMV、误解系等。
- 这些大类按**素材**或**风格**划分，彼此会重叠，一部作品可以同时属于几类。
- 比赛分赛道时以当届规则为准，不要只看标题里写的“AMV”或“静止系”。
- 想准确描述一部作品，就分别写出素材、表达目的、主要技术、协作方式和发布场合这五项。
- 各个标签的具体含义见[术语表](/mad/glossary)。
:::

## 常见类型速查

| 类型 | 主要素材 | 看点 | 容易误解的地方 |
| --- | --- | --- | --- |
| 动画系 | 现成的动画镜头 | 选镜、节奏、同步、叙事 | 不等于纯剪辑，也可以有大量合成 |
| 静止系 | 漫画、插画、立绘、CG | 拆层、运镜、排版，让静态图“动起来” | 不是“几张图加转场”，工作量往往很大 |
| 风格系 | 不限 | 运动、同步、视觉设计、个人风格 | 不是“特效多”的同义词 |
| 特效系 | 不限 | 合成、动态图形、视觉效果 | FX、VFX、MG 的边界因社区而异 |
| 混合系 | 两种以上媒介 | 不同素材共同承担叙事 | 偶尔插几帧别的素材不算 |
| GMV | 游戏画面、过场、宣传片 | 同 AMV，但素材是游戏 | 很多动画赛道不接收 |
| 误解系 | 现成动画 | 重排对白和情节，讲出原作没有的故事 | 只是打乱顺序不算 |
| ASMV | 动画＋对白／环境声 | 预告片式、剧情短片式结构 | 不是所有剧情向作品都是 ASMV |
| 手书／原创动画 | 作者自己画的 | 原创画面 | 部分比赛不接收 |

## 动画系

用现成的动画镜头，通过选镜、重排、同步、声音和合成做出新表达。可以只用一部作品，也可以跨多部选材。

常见方向：

- **纯剪辑（Raw）**：只靠镜头内容、切点、变速和结构完成表达；
- **剧情／情感**：重组原作事件和人物关系；
- **动作／舞曲**：让动作和镜头运动卡在音乐节拍上；
- **FX／VFX**：在剪辑之外加入大量图形、遮罩、跟踪和合成；
- **ASMV**：用对白、环境声和字幕做成预告片或短片式结构；
- **多素材 AMV**：从多部动画中选镜，用共同主题或视觉关系串起来。

## 静止系

以漫画、插画、立绘等静态图为主要素材，通过运镜、拆层、遮罩、变形、排版和合成让画面产生时间感。相关叫法：

- **静止画 M@D**：日本和中文社区的常见写法；
- **MMV**（Manga Music Video）：以漫画为主；
- **漫画系**：用漫画格、对白框和网点，靠拆格、补图、重新排版控制阅读顺序；
- **GAL／视觉小说系**：用立绘、事件 CG 和背景，靠表情差分和分层演出；
- **轻小说／插画系**：素材少，更依赖构图延展、文字和氛围。

静止系的“动”主要来自这些工作：

1. 把人物、头发、衣物、前景、背景拆成独立图层；
2. 修补被遮挡的背景；
3. 用 2.5D／三维空间、虚拟摄像机、景深和光影做镜头；
4. 重组漫画格和文字，引导观众的阅读顺序；
5. 用变形、粒子、逐帧动画或原创绘制补充动作。

## 风格系

中文社区用来指视觉设计、节奏和形式感比叙事更突出的作品，常见于短篇 edit 和 IG 风传播语境。它不是一个稳定的国际分类。

典型特征：

- 拉镜、抖动、旋转、模糊、变速形成连续运动；
- 色块、图形、文字和调色形成个人视觉语言；
- 对鼓点、音色、歌词做多层同步；
- 素材不限，动画、漫画、游戏、真人都可以；
- 常见几秒到一分钟的短片，也有完整的比赛稿。

只堆预设、没有稳定的运动逻辑和节奏设计，不会自然形成“风格”。

## 特效系

合成、动态图形或视觉效果占比明显的作品。几个相近说法：

- **FX**：中文资料里偏向字块、纯色层、缩放、图形和节奏效果；
- **VFX**：偏向重新构图、抠像、跟踪、三维空间、粒子和画面合成；
- **Motion Graphics（MG）**：以文字、形状和版式运动为主；
- **GFX**：圈内有时专指封面、海报等平面设计。

这些词经常重叠，也不代表技术高低。

## 其他类型

- **混合系**：动画、漫画、游戏 CG、立绘等共同承担主要表达。比赛可能要求按主要素材选赛道，也可能单设混合赛道。
- **GMV**（Game Music Video）：用游戏实机、过场或宣传片。以动画化过场为主时接近 AMV，以实机为主时更接近游戏剪辑。
- **特摄、真人、Non-Anime**：剪辑方法与 MAD 相同，但 B站分区和比赛是否接收要分别确认。
- **误解系**：重排对白、表情和事件顺序，让观众看到一个与原作不同的故事。关键是新故事要讲得通。
- **手书、原创动画、PV**：手书是作者自己画的二创动画；原创动画强调画面全部自制；PV 是以宣传为目的的影片。部分比赛会排除这些形式，原因是收稿范围不同，不是它们没有价值。

## 用五个维度描述一部作品

一部作品可以在每个维度上选一个或多个标签：

| 维度 | 可选标签 |
| --- | --- |
| 1. 素材 | 动画、漫画／插画、游戏、真人、原创、混合 |
| 2. 表达目的 | Action、Dance、Comedy、Drama／Romance、Character Profile、Psyche／Horror、Sentimental、Experimental |
| 3. 主要技术 | Raw（纯剪辑）、FX／VFX、Motion Graphics、Typography、Lip Sync、Match Cut、遮罩／抠像、补帧、原创动画、色彩设计 |
| 4. 协作方式 | Solo、Collab、MEP、IC、团队 |
| 5. 发布场合 | 比赛稿、活动／节庆、预告／PV／CM、Parody（パロ）、Alt-Opening、BGA／MV |

例如：“动画素材 · Action＋Character Profile · Raw · Solo · 比赛稿”。

“Raw”不代表技术低，“FX”也不代表更高级，它们只说明作品把主要精力放在哪里。

## IG／INS 风

IG 是 Instagram 的简称。“IG 风”指 Instagram 上流行的短篇 edit／AMV，它是一组风格的统称，不是单一技法。2019 年 NEW EDITORS CON 的科普列出了这些常见方向：

| 方向 | 特征 |
| --- | --- |
| 节奏型短 edit | 拉镜、抖动、曝光、调色、模糊、变速，密集同步 |
| 混合型 | IG 式处理结合较长篇幅剪辑或三维场景 |
| Motion Design | 平面设计、文字动画和图形运动 |
| Candy／FX | 明亮图形、色块和形状动画 |
| Pulse（脉冲） | 高频闪烁和跳切 |
| Celebrity Edit | 真人明星素材，变速和流畅衔接 |
| GMV Edit | 游戏实机或过场的短剪 |
| VFX／3D | 在三维空间里组织镜头和文字 |

## 中国大陆的两个创作圈

2020 年代以来，中国大陆的 MAD·AMV 创作者大致分成两个有交叉、但相对独立的圈子。这是对社群的观察，不是作品分类：

| | Bilibili 长篇圈 | 风格系短剪圈 |
| --- | --- | --- |
| 发布阵地 | B站投稿、合集、团队账号、赛事 | 短视频平台、作者个人账号、即时社群 |
| 常见时长 | 2—5 分钟，ASMV 更长 | 几秒到 1 分钟，比赛稿 1—3 分钟 |
| 看重什么 | 选镜、叙事、情绪、完整结构 | 同步、速度、运动、视觉设计、个人风格 |
| 交流入口 | 团队、赛事、B站作者、MAD吧旧教程 | 风格标签、短剪教程、作者群 |
| 资料保存 | 相对容易引用 | 跨平台搬运多，首发作者难追溯 |

依据：2024 年的[中国 MAD 创作者访谈研究](/mad/ccopw)（69 次访谈）把 B站 MAD 社群和 Instagram／抖音的 IG 风创作者分开讨论；2026 年 [IMAC FUN#4](https://www.bilibili.com/opus/1203002472552988705) 给动画系 AMV（2—5 分钟）、静止系（1 分 30 秒—5 分钟）和风格系（35 秒—3 分钟）分别设置了时长。

## Wuyi无疑《MAD的分类》

2019 年 Wuyi无疑发布的《MAD的分类》是中文社区流传最广的分类表。它把作品分成三大部分，其余称呼都作为可叠加的 Tag：

| 一级 | 二级 | 说明 |
| --- | --- | --- |
| 动画系 MAD（AMV） | Raw | 下分 Action、Dance、Fun／Comedy、Drama／Romance、Psyche／Horror |
| | VFX | 以大幅重新构图和视觉合成为主 |
| | FX | 剪辑与图形、色块、缩放等效果共同服务节奏 |
| 静画系 MAD | MMV | 以漫画为主要素材 |
| | 静止系 M@D | 强调静态素材、文案编排和分镜关系 |
| 混合系 MAD | — | 混用 ACGN 等不同媒介 |

原文列出的 Tag（ASMV、Candy、Over-Sync、复合 MAD、iMADs 等）已逐条收入[术语表](/mad/glossary)。作者自己说明这套分类偏向欧美 AMV 体系、并不完整，分类、技术、风格和平台也混在同一层级。
