# Source Index and Verification Status

This index records original MAD·AMV sources, local summaries of their use, source type, and link status. The summaries are stored locally so that MAD DOC can document each source's scope, limitations, and useful follow-up search terms while retaining links to the original material.

> Verification date: **2026-07-25**. Tieba and Bilibili pages have been verified for visible text or page information; other entries are cross-verified with public web pages, organization pages, papers, and official software documents.

## Status Legend

### Source Type

- **A｜First-hand/authoritative**: author’s original text, organizational rules, contemporaneous pages, official documents, academic papers;
- **B｜Community documentation**: participant recollections, specialist-site compilations, and navigation posts with strong value as leads;
- **C｜Personal perspective**: introductory articles, criticism, collections, and explanatory writing that should be checked against other sources.

### Link status

- 🟢 **Accessible**: The main text or main content can be read;
- 🟡 **Partially accessible**: The text is there, but pictures, attachments, mind maps, videos or some floors are missing;
- 🔴 **Unavailable/deleted**: the title, original URL, and navigation relationship are retained while an author copy or web archive is sought;
- ⚪ **Full text not yet verified**: discovered through a reliable index or search record, but the article body or attachments have not yet been checked.

## Information not included in official entries

The following content is only used as a discovery clue and is not included in the official entry:

- Encyclopedic reprint without author, date and source;
- Marketing articles that induce replying to keywords to receive "software/plug-ins/material packages";
- Popular science that absolutely separates MAD and AMV with a single technical feature;
- Unauthorized network disks, resource sites and cracked installation packages;
- Pages that are automatically aggregated by AI, have titles that have nothing to do with the text, or have other abbreviations MAD mixed into them;
- Only the search summary remains, and the broken link cannot confirm the original text.
